# News Explorer App: Front End

The News Explorer App is a responsive, single-page web application that provides real-time news data. This repository contains the client-side React code for the application.

## 🛠️ Technologies Used

- **Frontend Framework:** React.js, Functional Components, Custom Hooks
- **State Management & Routing:** React Context API, React Router DOM
- **Styling & UI:** HTML5, CSS3, BEM Methodology
- **Data Fetching & APIs:** Native Fetch API, News API Integration
- **Build Tools & Package Management:** NPM, Webpack / Create React App
